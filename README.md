# DnD Расписание

Небольшой сервис, чтобы собирать доступность игроков и видеть лучшие окна для игры.

## Запуск

```bash
python app.py
```

Откройте `http://localhost:5000`.

## Возможности

- Добавление доступности с комментариями.
- Список всех игроков и их окон.
- Подсказки лучших 30-минутных слотов по количеству игроков.

Данные сохраняются в `data/availability.json`.
